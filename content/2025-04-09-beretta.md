### ピエトロ・ベレッタ〘名〙（英Pietro Beretta）｟商標｠

① ピエトロ。イタリア語の男性名。英語のPeterに相当し、女性形はPiera。  
② ベレッタ。イタリアの老舗銃器メーカー。

#### 付録：ベレッタ92系・M9系の主なモデル

| モデル | 主な特徴 |
| --- | --- |
| 92 | フレーム側の安全レバーが特徴。初期型は段付きスライド |
| 92S | 安全レバーをスライド側に移し、デコッカーを追加 |
| 92SB | 撃針ブロックと左右両側の安全レバーを採用。『ノワール』に登場 |
| 92F | 角型トリガーガードを採用した米軍仕様。『BLACK LAGOON』や『ダイ・ハード』に登場 |
| 92FS | スライド破断時の脱落を防ぐ大型ハンマーピンを採用。『GUNSLINGER GIRL』に登場 |
| 92FS Inox | 銀色の耐食性重視モデルで、基本機構は92FSと同じ。ブルアカ(ミナ) |
| 92A1 | 銃身下に2溝のアクセサリーレールを備える92系の改良型。ブルアカ(ホシノ(臨戦)) |
| M9 | 米軍制式モデルで、軍用刻印と2ドット式照準器が目印 |
| M9A1 | 1溝のアクセサリーレールと改良されたグリップを備えるM9。ブルアカ(サヤ) |
| M9A3 | 直線的な交換式グリップとねじ切り銃身を備える砂色モデル |
| M9A4 | 光学照準器に対応し、G型デコッカーを標準装備したM9系の後継型 |
