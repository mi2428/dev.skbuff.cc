ソラコムのplan01sをCisco LTEルータで使用する方法メモ。ヤフオクで落札した C819GW-LTE-LA / IOS 15.6(3)M1 / MC7430。

## APNプロファイルの追加

APNプロファイルはモデム内に保存され、running-config には現れない。`*` はデフォルトデータ通信用プロファイル、`**` は LTEアタッチ用プロファイル。

```text
c819h1# cellular 0 lte profile create 1 soracom.io pap sora sora
c819h1# show cellular 0 profile

Profile password Encryption level: 7

Profile 1 = ACTIVE* **
--------
PDP Type = IPv4
PDP address = 10.193.176.160
Access Point Name (APN) = soracom.io
Authentication = PAP
Username: sora
Password: 120A0A0513
	Primary DNS address = 100.127.0.53
	Secondary DNS address = 100.127.1.53

  * - Default profile 
 ** - LTE attach profile

Configured default profile for active SIM 0 is profile 1.
```

## セルラーインターフェースの設定

`chat-script lte` と `dialer string lte` を対応させ、`dialer-group 1` の IP トラフィックで発呼する。
先ほど作成した `Profile 1` を controller 側のデータ通信用・アタッチ用プロファイルに指定する。
理由はわからないけど `dialer watch-list` を設定しないとデータ通信できなかった。

```text
chat-script lte "" "AT!CALL" TIMEOUT 20 "OK"
```

```text
controller Cellular 0
 lte sim data-profile 1 attach-profile 1 slot 0
```

```text
interface Cellular0
 ip address negotiated
 ip nat outside
 ip virtual-reassembly in
 encapsulation slip
 dialer in-band
 dialer string lte
 dialer watch-group 1
 dialer-group 1
 no peer default ip address
```

```text
dialer watch-list 1 ip 133.130.116.148 0.0.0.0
dialer watch-list 1 delay route-check initial 60
dialer watch-list 1 delay connect 1
```

```text
dialer-list 1 protocol ip permit
```

```text
ip route 0.0.0.0 0.0.0.0 Cellular0
```
