### Useless Use of Cat Award (UUOC) *noun* [C] (computing, humorous)

An imaginary award for using `cat` in a shell pipeline when the next command can read the file directly.

```text
$ cat file.txt | grep keyword  # awarded!!
$ grep keyword file.txt
```

```text
$ cat file.txt | wc -l  # awarded!!
$ wc -l < file.txt
```

---

ちなみにShellCheckにも [`SC2002: Useless cat`](https://github.com/koalaman/shellcheck/wiki/SC2002) という診断がある。
